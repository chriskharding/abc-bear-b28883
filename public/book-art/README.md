# Book art

Generated page illustrations go here. Naming:

- `book1-cover.png`, `book1-p1.png` … `book1-p7.png`
- `book2-cover.png`, `book2-p1.png` … `book2-p8.png`
- `book3-cover.png`, `book3-p1.png` … `book3-p7.png`

Square images, ~1024×1024 PNG. The reader shows the image when the file
exists and falls back to the page's emoji when it doesn't, so partial sets
are fine. Drop files in, rebuild, done.
